# Security Policy

## Supported versions

Security fixes go into the `devel` branch and are included in the next release.
Only the latest release of each component (`platform`, `sdk` / the `prometheus_api`
image, `agent-template`) receives fixes.

## Reporting a vulnerability

**Please do not report security vulnerabilities in public GitHub issues,
discussions, or pull requests.**

Report it privately in one of these ways:

1. **GitHub private vulnerability reporting (preferred).** Go to the repository's
   [Security tab](https://github.com/idaholab/prometheus_core/security) and choose
   **Report a vulnerability**.

Please include as much of the following as you can:

- The affected component(s) and version or commit
- A description of the vulnerability and its potential impact
- Steps to reproduce, a proof of concept, or the affected code paths
- Any suggested mitigation or fix

## What to expect

- We aim to acknowledge your report within **5 business days**.
- We'll keep you informed while we investigate and work on a fix, and may ask
  for more information.
- Once a fix is available, we'll coordinate the disclosure timeline with you and
  credit you in the advisory unless you'd rather stay anonymous.

Please give us a reasonable amount of time to fix the issue before disclosing it
publicly.
